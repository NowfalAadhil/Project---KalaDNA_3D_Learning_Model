# KALA-DNA — 3D Learning Model

**Smart Heritage Skill Preservation · _We preserve the skill, not just the artifact._**

An interactive, browser-based 3D simulation of **KALA-DNA**, our Smart India Hackathon 2026 idea. It shows how a traditional craftsperson's own tool can be turned into a sensing device, how a master's technique becomes a measurable **Technique Fingerprint**, and how an apprentice is coached toward that fingerprint in real time.

## The idea

Traditional crafts are learned by watching and repeating. The knowledge sits in the master's hands (grip pressure, tool angle, stroke speed, rhythm) and is rarely written down. Most heritage-tech records the finished artifact or a video of the process. KALA-DNA captures the technique itself.

1. **Capture:** A clip-on sensor module on the artisan's own tool records pressure, angle, speed and timing while they work.
2. **Fingerprint:** That data becomes a **Technique Fingerprint**, a measurable signature of how the master performs the technique.
3. **Practice:** An apprentice uses the same instrumented tool.
4. **Correct:** The system compares the apprentice to the master live and gives haptic, LED and on-screen cues (**Digital Guru** mode).

```
Master Artisan  ›  Smart Tool  ›  ESP32  ›  AI Engine  ›  Feedback + Dashboard
```

## What the demo shows

- **3D Smart Tool:** a chisel with a clip-on module containing an ESP32 (BLE / Wi-Fi), an IMU (accelerometer + gyroscope), FSR grip-pressure pads, a force sensor, a vibration motor, an LED cue ring, and a mount with a Li-Po battery.
- **Inspect Smart Tool:** labels each hardware part in the 3D view.
- **Exploded View:** separates the module so you can see every component.
- **Master vs apprentice:** two animated strokes side by side, with live pressure / angle / speed curves.
- **Apprentice controls:** sliders for grip pressure, tool angle offset, stroke speed and stroke cycle time.
- **Observe mode:** watch the master and the apprentice mirrors the technique.
- **Guided practice:** the apprentice gradually improves toward the master's fingerprint.
- **Digital Guru panel:** a plain-language cue for the biggest deviation (for example _"Ease your grip — pressure is above the master"_), a haptic status, a 0–100 technique-match score, a stroke history chart, and a radar chart of the fingerprint.
- **Learning steps:** Observe → Practice → Correct → Mastery.
- **Impact panel:** the solution summary, social / economic / environmental impact, roadmap and research basis.

## Run it locally

The project is a **single HTML file** (`index.html`) that uses [three.js](https://threejs.org/) `0.164.1`.

**Easiest:** open the file in a modern browser with an internet connection. It loads three.js from a CDN (jsDelivr, with unpkg as a fallback).

**Offline / local three.js:**

```bash
npm install three@0.164.1
python -m http.server 5500
# then open http://localhost:5500
```

The page looks for `./node_modules/three/` first, then falls back to the CDNs.

**Requirements:** a browser with WebGL enabled (Chrome, Edge, Firefox, Safari). If you see a WebGL banner, turn on hardware acceleration in your browser settings.

## Deploy with GitHub Pages

1. Rename the file to `index.html` and push it to the repo root.

## How the simulation works

- The **master** follows a fixed 4-second stroke cycle, with pressure, angle and speed defined as smooth curves over the stroke.
- The **apprentice** uses the same curves, modified by the slider values for pressure, angle offset, speed and cycle time.
- Each channel's deviation from the master is normalised, and the four are combined with weights into a live **technique-match score** out of 100.
- The **Digital Guru** picks the channel with the largest deviation and turns it into a cue. Haptic feedback is shown as an animated status and the tool's vibration motor and LED ring respond in the 3D scene.
- In **Guided practice**, the apprentice's parameters ease back toward the master's, and the carved groove in the 3D wood block deepens as strokes improve.
